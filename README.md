One line I would send back to my younger self — 1 line, 96 characters, 1 bike, 1 gate, 1 last summer. A small, specific warning about a small, specific sale: the kind of thing only the older self who watched the gate go quiet could say.

> Don't sell the red bike — the summer you do is the last summer anyone waits for you at the gate.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22+) validates the line — 1–200 characters, a single line, no leading or trailing whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt` when unset), and prints it to stdout. If the line ever broke the length or content rule, the program would refuse to run instead of writing a bad entry.
